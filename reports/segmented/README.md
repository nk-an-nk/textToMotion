# 分割発話とジェスチャー：Kimodo / ARDY

同じ5区間の発話音声・動作指示・seed（0〜4）・再生開始フレームを使っています。各モデルで区間ごとの動作を新規生成し、発話と同時に開始して連結しました。両方の連結動画は正面1080p / 30fps / 14.133秒 / 424フレームです。

| モデル | 連結動画 | 個別動画と計測 | 推論経路 |
|---|---|---|---|
| Kimodo | [MP4](english-lesson/combined.mp4) | [5区間・時間](english-lesson/README.md) | NVIDIA公式オンラインデモ / SOMA77 / 30fps |
| ARDY | [MP4](english-lesson-ardy/combined.mp4) | [5区間・入力→生成時間](english-lesson-ardy/README.md) | 公開コミュニティサービス / Horizon40 / Core27 / 20fps |

5区間の骨格生成時間合計：Kimodo 72.91秒 / ARDY 115.29秒。キュー・ネットワーク・テキスト処理・ローカル変換を含む異なるサービスでの実測で、同じGPUの速度比較ではありません。動作の自然さや意味的一致は未採点です。

音声の追加生成はARDY側で行わず、Kimodo版の実音声をハッシュ照合して共有しました。ARDYはネイティブ20fpsの動作を各発話区間へ合わせて30fpsで描画しています。モデルの最短動作はKimodo 2秒 / ARDY公開サービス1秒で、短い発話の再生速度への影響も異なります。

骨格生成とMP4完成までの処理時間は各フォルダーのCSVにあります。新しいARDY記録は入力・完了のUTC時刻と、待ち時間を含む経過時間も保持します。以前のKimodo記録に入力時刻はないため、経過時間は推定していません。
