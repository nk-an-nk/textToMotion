# ARDY：5区間の新規生成・同期・連結

[**音声付き連結動画（combined.mp4）**](combined.mp4) — 正面1920×1080 / 30fps、14.133秒・424フレーム。

Hugging Face認証後、NVIDIA ARDYの学習済みモデルで、以下の各区間の動作を新規生成しました。動作指示・seed・音声・再生開始フレームは [Kimodo版](../english-lesson/README.md) と同じです。④の英語2文は1区間、⑤の `I'm happy!` は同じ区間の一部です。音声と動作は各区間の同じフレームで開始し、個別5本を連結しています。

骨格生成の5区間合計：**115.29秒**。連結を含む書き出し：1038.91秒。成功した処理時間合計：1154.20秒。最初の動作指示の入力から連結MP4完成までは1219.86秒でした。

「入力→骨格」は動作指示を生成処理へ渡す直前から、正規化した骨格JSONの生成完了までの実測時間です。リモートのキュー・テキストエンコード・推論・転送・ローカル変換を含みます。「入力→MP4（経過）」は同じ入力時刻から各動画の完成までで、別区間の生成や描画開始待ちも含みます。「処理」は骨格生成とその区間の書き出しだけの合計です。入力・生成・動画完成のUTC時刻も保存しています。初回の認証引数エラーの待ち時間は成功処理に含めていません。

[骨格生成時間CSV](timings.csv)、[MP4までの時間CSV](render-timings.csv)、[入力・開始フレーム・出典](manifest.json)、[映像書き出し記録](combined.json)、[全動画の検査記録](validation.json) を保存しています。

モデルは **nvidia/ARDY-Core-RP-20FPS-Horizon40**、Core27、ネイティブ20fps。公開コミュニティSpace [hugging-apps/ardy-human-motion](https://huggingface.co/spaces/hugging-apps/ardy-human-motion) のリモート推論です。NVIDIAがホストした公式デモ、研究室RTX 5070のローカル実行、既定Core8の実測とは区別します。ソースrevision `344cab081ed29a48879683c0a78f80918b5a1681` とSHA-256を固定し、応答の入力文・seedと実NPZ内の文・骨格・フレーム数・ハッシュを照合しています。

5区間ともテキスト条件付きです。音声波形をモデルに渡しておらず、音声条件付きのco-speechモデルとしては扱いません。英語の動作指示は発話内容に合わせて設定したものです。自然さ・意味的一致は採点していません。

音声は以前にRealtime API / `gpt-realtime-2.1` / `marin` で生成した5区間を、元の生成記録とともにそのまま共有しています。今回のOpenAI API呼び出しは0回です。元音声の生成時間は `speech_original_generation_seconds` に保持し、今回の音声生成時間は0秒と記録しています。

公開サービスの最短動作は1秒です。動作を20fpsの境界へ切り上げて生成し、再生は発話区間へ合わせます。①では1秒の新規動作を約0.967秒で再生。②〜⑤の元動作は3.70 / 2.90 / 2.30 / 4.40秒です。境目の姿勢は最大250ms補間し、腰の位置を引き継ぎます。音声RMSによる口の開閉を適用しています。

全6本を最後までデコードし、H.264＋AAC・1080p・30fps・424フレームの連結版を確認しました。各音声を元PCMと照合した開始位置の誤差は0サンプル。5つの骨格出力は異なり、描画フレームの欠落と区間境目の腰の位置の飛びはありません。完成後の同じ生成コマンドはAPIを再実行せず、出力を保持します。

アバターは AvatarSample_VRM1.0 / pixiv VRoid Project。個人の非営利研究用の描画動画として出典を表示し、再配布不可のVRM本体はGitへ追加していません。ネイティブ1080pのオフライン描画で、クラウドCPUの書き出し時間は研究室GPUの性能測定ではありません。
