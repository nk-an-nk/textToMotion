## 従来モデルの会話応答とKimodoクラウド環境版

従来の7モデルの実測を維持し、先頭行をユーザー指定の表示名「Kimodo（研究室版）」とし、その直下に「Kimodo（クラウド環境版）」としてB300・100ステップの会話実測を追加しています。クラウド環境版は音声初受信0.603秒、生成処理1.933秒、骨格受信4.972秒、音声との差4.370秒です。GPU以外に常駐化・中継経路も異なる条件の比較です。

![従来モデルとKimodoクラウド環境版](original-models-b300.png)

「研究室版」は表の表示名です。この行の元のKimodo実測は公式オンライン経路であり、研究室のRTX 5070実機上の推論時間ではありません。

## 計測の意味と出典

「生成処理」は会話実行時の骨格生成単体の時間。「動作完了観測」は骨格データを受信した時点で、アニメーション再生終了時点ではありません。「音声との差」は骨格受信と最初の音声受信の差です。丸め前の値から差を計算しています。

- [追加実験の実測CSV](../masked-models-20261016/summary.csv)
- [従来モデル会話実測CSV](../model-comparison/runpod-20261014/audio-response-times.csv)
- [Kimodo B300会話実測CSV](../kimodo-b300-20261015/dialogue-times.csv)

従来表は常駐化前、追加実験とKimodo B300は常駐化後です。実装経路・英訳の有無などの条件が異なるため、GPU性能だけの比較ではありません。
