# 返答生成モデルを切り替える比較（0.7.0）

画面上部の「返答生成モデル」から次の2種類を選べます。停止してから切り替えてください。モデル切替で会話履歴をリセットします。選択はアプリ再起動後も保持します。

| 表示 | APIへ送る固定バージョン |
| --- | --- |
| GPT-4.1 mini（現在・軽量） | gpt-4.1-mini-2025-04-14 |
| GPT-4.1（比較用・上位） | gpt-4.1-2025-04-14 |

「テキストで会話」と「会話を開始」の両方に適用されます。音声入力はKebbi標準ASR、読み上げは標準TTSです。

## 返答生成とモーション選択の分離

両モデルとも同じ2段階の処理を使います。

1. 選択したモデルに、発話・直近の会話履歴・言語・共通の会話指示を渡し、返答文章だけを生成させます。モーション一覧やカテゴリは渡しません。
2. 確定した全文章を固定のモーション選択モデルにまとめて渡し、文ごとの動作を選ばせます。文章の書き換えは許可しません。
3. アプリが一文につき一動作で発声・再生し、継続会話では自動で聞き取りへ戻ります。

動作選択モデルはバックエンドの `LLM_MODEL` で固定し、現在は `gpt-4.1-mini-2025-04-14` です。①全動作ID直接選択、②カテゴリ7種・25種の選択方式は従来どおり切り替えられます。モデル変更の比較では、これらの条件と言語を揃えてください。

返答ごとのAPI呼び出しは2回です。旧版の文章・動作を一括生成する1回の呼び出しと、全体待ち時間を同条件の結果として扱わないでください。「原則1〜2文」の推奨は外したままで、最大6文・合計400字は維持します。

## 速度と記録

最新の速度表示・履歴・CSVに以下を追加しました。

- `reply_model`: 実際に要求した返答生成モデル。
- `motion_model`: モーション選択に使った固定モデル。
- `text_generation_ms`: バックエンドが文章生成APIの要求から応答受信・検証までに要した時間。
- `motion_selection_ms`: 続くモーション選択APIの要求から応答受信・検証までに要した時間。

「LLM全体待ち」はアプリからバックエンドへの通信と両段階を含みます。「返答開始」はASR結果確定または手動送信からTTS開始通知までです。モデルだけの比較には文章生成時間を使い、体感速度には返答開始の時間も確認してください。文数・文章の長さ・生成内容によって時間は変わるため、同じ入力を複数回試してください。

平均はモデル・モーション選択モデル・実験条件・入力方式・言語ごとに分けます。従来の一括生成記録も混ぜません。通常の速度記録に会話本文・APIキーは含めません。本文を残す場合は設定で「会話本文も記録する」とJSONL保存を有効にします。

## APIと互換性

`POST /api/respond` に `reply_model` を追加します。指定できるのは上記2つのIDだけです。未指定の旧クライアントは従来の一括生成を継続します。新しいアプリはどちらのモデルでも2段階方式を指定します。

応答には既存の文章・文単位モーションに加え、上記のモデル・時間メタデータを返します。文章生成失敗や動作の個数不一致ではエラーとし、別モデルへの自動切替や文章の黙った置換は行いません。履歴はモデル・言語・実験条件ごとに分離し、会話リセットでまとめて破棄します。

## 確認

合成の日本語学習入力「きれいかったです」の修正を両モデルへ送り、正しい言い方を含む文章生成と、固定miniによる文ごとの動作カテゴリ選択の実接続を確認しました。各1回なので品質や速度の優劣を判定する比較ではありません。元の応答・時間は作業領域 `Kebbi実験結果/2026-10-29/モデル切替確認/api-probes.json` に記録しています。

バックエンドの自動テストでは、選択モデルが文章生成だけに使われること、動作モデルが固定されること、文章を保持したまま各文に動作を割り当てること、不正な出力や未許可モデルの拒否、履歴の分離・破棄を検証します。JavaのHTTP結合テストでは従来方式と両モデルの指定を3つの動作選択条件で通します。

モデルの仕様: [OpenAI Docs: GPT-4.1](https://developers.openai.com/api/docs/models/gpt-4.1)、[GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)。これらは最新版という位置づけではなく、既存モデルとの比較用にバージョンを固定しています。
